Question 4

set.seed(125)
B <- 2000
boot_cor <- numeric(B)
for (i in 1:B) {
  idx <-sample(nrow(air), replace = TRUE)  
  boot_sample <- air[idx,]
  boot_cor[i] <- cor(boot_sample$NO2, boot_sample$PM10)
}
round(cor(air$NO2, air$PM10), 3)
## [1] 0.399
round(sd(boot_cor),3)
## [1] 0.138

The bootstrap method is used to estimate the variability of the correlation between NO2 and PM10 by repeatedly resampling the data with replacement. A total of 2000 bootstrap samples are generated, and the correlation is calculated for each sample.

The original correlation is 0.399, and the bootstrap standard error is 0.138. This shows that there is some variability in the estimated correlation across different samples.

Since the standard error is not very small compared to the correlation value, it suggests that the relationship between NO2 and PM10 is moderate but not very strong and may vary across samples.

set.seed(125)
B <- 2000
boot_cor <- numeric(B)
for (i in 1:B) {
  idx <-sample(nrow(air), replace = TRUE)  
  boot_sample <- air[idx,]
  boot_cor[i] <- cor(boot_sample$NO2, boot_sample$PM10)
}
round(cor(air$NO2, air$PM10), 3)
## [1] 0.399
round(sd(boot_cor),3)
## [1] 0.138
Q <- quantile(boot_cor, c(0.05, 0.95))
Q[1]; Q[2]
##        5% 
## 0.1660039
##       95% 
## 0.6096804

The 90% confidence interval for the correlation coefficient is obtained using the bootstrap quantile method. Based on the results, the interval ranges from 0.166 to 0.610.

This interval is entirely positive, which suggests that there is a positive relationship between NO2 and PM10. It also indicates that the true correlation is likely to lie within this range.

Since the interval is not very narrow, it shows some uncertainty in the estimate, but overall the association between the two pollutants remains moderate and positive.
